## 5. P11 (current branch) — how it works

Spec: `docs/superpowers/specs/2026-10-24-p11-liquid-xray-hover-design.md` (Revision 4 table,
P11-R4-1…6). Plan: `docs/superpowers/plans/2026-10-24-p11-liquid-xray-hover.md`. ADR-014 in
`docs/decisions/README.md` (revisions 2–4). The original x-ray idea was dropped in revision 4.

**Liquid states.** `outer` = near-circle, 80px, faint wobble, anywhere outside the grid.
`inner` = over `.ProductGrid`, 280px, deep morph. The change animates both ways (350 ms).

| File                                      | Role                                                                                                    |
| ----------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| `lib/motion/liquid.ts`                    | `LENS` sizes; `lensOutline()` builds the SVG path (seeded PRNG, 6 harmonics, depth controls the wobble) |
| `components/motion/CursorLiquid.tsx`      | Client. Mounted once in `components/layout/SiteFrame.tsx`. Fine pointer + no reduced motion only        |
| `components/product/lensTextures.ts`      | `LIQUID_TINT` (orange→purple SVG noise) and `FILM_GRAIN` data URIs                                      |
| `app/globals.css`                         | `.CursorLiquid__colour` multiply blend, grain animation, `.CursorLiquid__button` purple/orange colours  |
| `lib/motion/push.ts`                      | `pushFor()` — neighbour push (radius 260, max 6px, scale ≥ 0.97)                                        |
| `components/product/ProductGrid.tsx`      | Holds the one open card, re-measures on resize, runs the neighbour push once per frame                  |
| `components/product/ProductHoverCard.tsx` | Card frame grows from the photo box with `clip-path: inset()` (0.28 s)                                  |
| `components/product/ProductCardFace.tsx`  | `FRAME_PX = 16`, card classes                                                                           |
| `lib/hooks/useFinePointer.ts`             | `(hover: hover) and (pointer: fine)` via `useSyncExternalStore`                                         |

**Mechanism.** Two `position: fixed` layers (z-35: above content and the hover card, below the
header, consent bar, quiz and dialogs) share one SVG `<clipPath>`. Every animation frame the path
is rewritten from `lensOutline()` at the pointer position (no lag, no follower).

- Colour layer: tint + grain with `mix-blend-mode: multiply` on the layer itself (a clip-path
  creates its own blending group, so the blend must sit on the clipped element).
- Button layer: a copy of the hover card's `.ProductAction`, moved each frame to the real
  button's `getBoundingClientRect()`. It only shows inside the liquid, so only the overlap
  changes colour: purple; orange (`data-hover="true"`) while the real button is hovered.

**Tests.** Unit: `liquid.test.ts`, `push.test.ts`, `CursorLiquid.test.tsx`. E2E:
`e2e/cursor-liquid.spec.ts`, `e2e/liquid-lens-resize.spec.ts`. Evidence scenarios:
`liquid-journey-vi`, `liquid-outer-vi`, `liquid-over-card-vi`, `liquid-on-button-vi`
(published to `evidence/pr-14`).

## 6. Gotchas learned the hard way

- Lint (React compiler rules): no synchronous `setState` inside effects, no reading/writing refs
  during render, no impure calls (`Math.random`, `Date.now`) during render — move them to effects.
- E2E: React keeps a hidden pre-rendered copy of the grid; select with `:visible`
  (`.ProductGrid__list:visible > .ProductTile`). Scroll the tile to the centre before hovering,
  then wait ~400 ms for the card reveal. The open hover card covers the tile, so click the card
  (`.ProductHoverCard__name`), not the tile link.
- Perf: `/vi` LCP sits near the budget in some runs; the LCP element is the consent-bar text.
  Large data URIs in the global stylesheet raised LCP — keep textures in the component.
- Two quiz unit tests can time out under full-suite load; they pass on rerun.
- The owner sometimes sends screenshots from `/var/folders/...`, which the agent cannot read
  (EPERM). Ask them to paste the image into the chat.
