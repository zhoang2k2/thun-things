# Components Directory

UI components are organized strictly by feature domain:

- `ui/`: Generic accessible primitives (Button, Input, Dialog, Skeleton).
- `layout/`: Global shell components (Header, Footer, LocaleSwitcher).
- `home/`: Home-specific interactive components (HeroScroll, ProductDragGrid).
- `shop/`: Catalog components (ProductCard, ProductGrid, StatusBadge).
- `quiz/`: Quiz bot components (QuizLauncher, QuizBubble, QuizPopup).
- `motion/`: Motion primitives and token definitions (`tokens.ts`, Reveal).

See [`docs/architecture/overview.md`](../docs/architecture/overview.md) for architectural guidelines.
